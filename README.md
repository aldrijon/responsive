# Responsive Web Project

Projeto de site front-end com páginas HTML, estilos CSS e scripts JavaScript. O objetivo é praticar estruturação de páginas, layout responsivo e navegação.

## Tecnologias
- HTML
- CSS
- JavaScript

## Como visualizar
1. Clone ou baixe o repositório.
2. Abra `index.html` no navegador.
3. Para testar o fluxo visual de login, abra `login.html`.

## Arquivos principais
- `index.html` — página principal.
- `login.html` — tela de login.
- `style.css`, `responsive.css`, `print.css` — estilos.
- `scripts.js`, `menu.js` — comportamento de interface.
- `images/` — imagens do projeto.

## Segurança
O arquivo JSON de credenciais OAuth que estava versionado foi removido do branch principal. **A remoção do arquivo não revoga nem invalida uma credencial que já tenha sido exposta.** Se a credencial for real, revogue-a/regenere-a no Google Cloud antes de reutilizar o projeto. O histórico Git ainda pode conter a versão anterior; a limpeza de histórico precisa ser avaliada separadamente.

Não versione arquivos de credenciais, tokens, senhas ou configurações privadas. Use variáveis de ambiente ou arquivos locais ignorados pelo Git. Este projeto é de portfólio e não deve ser considerado um sistema de autenticação seguro sem revisão adicional.
